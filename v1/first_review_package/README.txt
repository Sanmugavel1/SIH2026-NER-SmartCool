COLD CHAIN MANAGEMENT — FIRST REVIEW PACKAGE

Files:
- dashboard.html: offline interactive dashboard mockup. Open directly in a browser.
- cold_chain_prototype.scad: editable 3D prototype. Open in OpenSCAD (free). Change `view` to assembled/exploded/top/front/rear and render.
- sensor_wiring_diagram.svg: editable vector wiring diagram. Open in Inkscape (free) or a browser.
- FIRST_REVIEW_PROGRESS.txt: immediate next-step sequence.

The prototype model follows the current presentation architecture:
ESP32, two DS18B20 probes, SHT31, reed switch, power monitoring, compressor current sensing, DS3231 RTC, MicroSD, communication module, OLED, buzzer/LED, battery monitoring and vaccine carrier enclosure.

Important: the dashboard values are simulated. Do not present them as measured experimental results.
